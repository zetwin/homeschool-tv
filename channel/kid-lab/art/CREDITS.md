# Where the Kid Lab's art comes from
Rendered once with `node tools/kid-art/render.mjs`, so children's devices need no 3D.
- **3D scenes and objects** (`room`, `island`, `icon-*`): modeled in code for this project, in `tools/kid-art/`, using three.js (MIT).
- **Textures** in `tools/kid-art/tex/` and `leather.jpg`: Poly Haven, listed as CC0. https://polyhaven.com/license
- **Other photos**: from `channel/assets/img/`, with sources in `channel/assets/img/credits.json`. Some need attribution before any public use.
- **Fox picture**: Fluent Emoji by Microsoft (MIT).
Samples only. An illustrator or 3D artist is still needed before launch.
